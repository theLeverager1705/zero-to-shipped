Anchor: the family co-pilot for Gen Alpha

Anchor connects the three people who shape a Gen Alpha kid’s week. Kids check in and run quests, parents get an AI weekly brief grounded in real signals, and teachers close the loop from school.

What it does

  • Kids: a 30-second mood and energy check-in, quests that earn screen time, and a screen-time budget they can see.
  • Parents: a weekly brief written by Claude on Amazon Bedrock, with wins, watch-outs, patterns and conversation starters, plus an AI coach.
  • Teachers: notes home that become quests, and a consent-aware class pulse.

How it is built

React on Amazon CloudFront and S3, a Node.js API on AWS Lambda behind Amazon API Gateway, Amazon DynamoDB for family workspaces, Claude on Amazon Bedrock for insights with a rules-engine fallback, and the AWS CDK for infrastructure. Built with Claude Code for AWS Zero to Shipped 2026 (Startups lane).
